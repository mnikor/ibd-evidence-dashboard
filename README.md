# IBD Evidence Intelligence

Prototype dashboard for evidence planning in inflammatory bowel disease (TREMFYA, icotrokinra, JNJ-4804) against competitors.
**Prototype for internal discussion. Not an official J&J system.** It combines public data (ClinicalTrials.gov, PubMed,
congress abstracts, labels, company filings, guidelines, HTA decisions) with clearly labelled simulated inputs.
Every card shows whether its data is fact, calculated, AI-inferred or simulated.

## Two versions, one code base
| Version | URL | File |
|---|---|---|
| Full | `/` | `dashboard/index.html` |
| Simplified | `/simple.html` | `dashboard/simple.html` (generated by `scripts/build_simple.py`) |

A Full / Simplified switch in the top bar moves between them on the same page.

## Run locally
```bash
python3 scripts/serve.py 8765
```
Open http://127.0.0.1:8765. No packages to install (Python 3.9+ standard library only).

## Deploy on Domino
1. In Domino, create a project from this Git repository (or add it as an imported Git repo and set the working directory to its root).
2. Use any environment with Python 3.9+ (no extra packages).
3. Publish → App → app file `app.sh`. It starts the server on `0.0.0.0:8888`, which Domino expects.
4. Open the app URL; add `simple.html` to the URL for the simplified version.

Notes for Domino:
- The Data Editor saves edits to `data/overrides/overrides.json` inside the running app. Depending on your Domino setup, these
  files may not persist after the app restarts; commit them back to Git if edits must be kept.
- Access control comes from Domino's app permissions; the dashboard itself has no login.

## Rebuild the data
```bash
python3 scripts/build_dataset.py          # data/raw + scripts/curated_public.py -> data/json
python3 scripts/build_dashboard_data.py   # data/json -> dashboard/data.js
python3 scripts/build_simple.py           # dashboard/index.html -> dashboard/simple.html
python3 scripts/build_standalone.py       # single-file HTML copies in dist/ (not in Git)
```

## Layout
- `dashboard/` – the app (HTML/JS, D3) and its data file `data.js`
- `scripts/` – data fetch and build scripts, local server
- `data/` – raw downloads, processed JSON, Excel export, method notes (`data/README.md`)
- `deck/` – source of the metrics slide deck
- `DATA_SPEC.md`, `SCALE_PLAN.md` – data model and scaling plan
